# LUVI Finanças v6.0.1
Refinamento da experiência mobile com base no teste real da v6.0.0.

- Atalhos superiores reduzidos a Nova movimentação, Transferir e Dashboard.
- Contas, Categorias e Grupos deixam de se repetir na Home e continuam acessíveis pelo menu Mais.
- Navegação inferior agora contém apenas Início, Movimentações e Mais.
- Corrigido conflito visual entre atalhos superiores e seletor do período.
- Padronizados cantos das principais superfícies/cartões.
- Subtelas ganharam área rolável própria e rodapé de ações protegido.
- A barra inferior é ocultada enquanto uma subtela está aberta, evitando cobrir botões.
- Desktop, backend, banco e migrations não foram alterados.
