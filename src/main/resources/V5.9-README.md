# LUVI Finanças v5.9 — Ajustes mobile e sessão

- O cadastro de lançamento passa a carregar categorias pessoais e de todos os grupos acessíveis quando estiver em Visão geral/Conta; em contexto de Grupo, mantém apenas as categorias daquele grupo. As opções mostram o escopo para distinguir nomes repetidos.
- Gerenciamento de categorias otimizado para celular: seletor de estrutura em linha própria, layout compacto, lápis/lixeira e switch Ativa/Inativa.
- Ações de editar/excluir de contas e movimentações também usam ícones compactos com title/aria-label.
- Tratamento global de sessão expirada nas chamadas fetch: redirect para /login?expired.
- Login mostra: "Sua sessão expirou. Acesse novamente."
- Sem nova migração Flyway; banco permanece em V3.
