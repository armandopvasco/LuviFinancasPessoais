Correção estrutural das subtelas e área segura.

Fluxos pai -> filho agora substituem a tela anterior:
- Contas financeiras -> Nova/Editar conta -> volta para Contas.
- Contas financeiras -> Compartilhar -> volta para Contas.
- Categorias -> Nova/Editar categoria -> volta para Categorias.
- Grupo -> Membros -> volta para Grupo.
- Membros -> Convidar -> volta para Membros.

ESC e botões X/Cancelar seguem a mesma regra.

- 16 px em desktop.
- 10 px em mobile.
- margem nos quatro lados, inclusive abaixo do rodapé.
- campos limitados à área interna da subtela.

Sem migration de banco.
